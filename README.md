# EchoTrans 🎙️

**不必將語音送往雲端，透過本機 GPU 即可即時聽寫與翻譯，並以雙語字幕顯示。**

EchoTrans 是為演講、課程、線上會議與影片收聽設計的本機語音辨識／翻譯專案。專案已從早期 Python + Vosk 架構，轉向以 **Rust** 開發的 **RamenListen** 系列；目前的 Rust 原始碼位於 [`EchiTransRS/`](./EchiTransRS/)，版本為 **v0.7**。

> **目前狀態：v0.7 原始碼測試版。** 儲存庫提供 Rust 專案，但不代表已有可直接下載的 Windows 安裝程式或經過實機驗證的 EXE；模型與 Windows GPU 執行環境仍需在實機測試。

## ✨ 核心特色

- **全本機辨識與翻譯**：使用 **Qwen3-ASR 0.6B** 辨識語音、**Hy-MT2-1.8B** 翻譯短句；不依賴雲端翻譯 API。
- **啟動即準備模型**：首次啟動自動下載所需模型及本機 Vulkan 翻譯執行元件，完成預載後即可按下開始收音。首次下載需要網路，之後模型推論在本機進行。
- **即時雙語字幕與回捲歷史**：置頂、半透明、可拖曳的單視窗字幕，平常聚焦最新約三句；可用滑鼠滾輪向上查看本次最多 500 句原文及翻譯，滾回底端自動追蹤新字幕。
- **短句優先**：依語音停頓切句，支援辨識中的預覽更新；翻譯以串流方式逐步顯示。
- **無背景黑色終端**：Windows GUI 主程式、GPU 偵測與 Hy-MT2 子程序不另外開啟主控台視窗。
- **語言彼此獨立**：介面預設跟隨 Windows 顯示語系，翻譯預設固定為**繁體中文（台灣）**，不會因系統是英文而改翻成英文。
- **台灣繁體最佳化**：對繁體中文翻譯使用台灣用語指令，必要時由純 Rust OpenCC（`S2twp`）進行字形與詞彙轉換。
- **只保存原文逐字稿**：正式辨識完成的原文自動寫入文字檔；預覽字幕及翻譯內容不混入原文紀錄。
- **設定自動保存**：語言、字幕尺寸、透明度及停頓等設定會保留；v0.7 支援沿用 v0.6 設定。

## 🧠 技術架構

| 元件 | 技術 | 主要任務 |
| --- | --- | --- |
| 主程式與介面 | Rust + egui / eframe | 字幕顯示、設定及本機紀錄 |
| 語音輸入 | CPAL + VAD | 擷取預設麥克風、重採樣及停頓切句 |
| 語音辨識 | Qwen3-ASR 0.6B（wgpu） | 自動辨識語言並產生原文 |
| 翻譯 | Hy-MT2-1.8B GGUF | 透過本機 Vulkan llama-server 翻譯 |
| 台灣繁體轉換 | ferrous-opencc | 必要時修正繁體字形及詞彙 |
| 多語介面 | Rust 靜態詞庫 | 直接跟隨 Windows 語系，不呼叫 AI |

為了保持軟體簡單，**Rust 版不再使用 Vosk、Google 翻譯、Gemma 3、Ollama、Argos Translate、Moonshine、Python 或 uv**，也沒有 CPU 推論備援。

## 🌐 v0.7 語言設定

| 項目 | 預設值 |
| --- | --- |
| 介面語言 | 跟隨 Windows 顯示語言，可手動切換 |
| 語音辨識來源 | Qwen3-ASR 自動偵測，可選特定來源語言 |
| 翻譯目標語言 | **繁體中文（台灣，`zh-Hant`）**，可自行修改 |
| 翻譯模型 | Hy-MT2-1.8B |
| 台灣繁體轉換 | 必要時套用本機 OpenCC |
| 設定保存 | 自動保存，下次啟動沿用 |

介面提供繁體中文、簡體中文、英文、日文、韓文、法文、德文、西班牙文、葡萄牙文及俄文的內建詞庫；未提供的系統語系回退英文。**介面語言與翻譯目標語言互不影響**。

## 💻 執行需求

目前的 Rust 版以以下環境為目標：

- **作業系統**：Windows x64。
- **顯示卡**：NVIDIA 獨立 GPU，**最低 6 GiB VRAM（測試支援），建議 8 GiB 以上**；翻譯元件採 Vulkan，現行程式也會檢查 NVIDIA 驅動與顯存。
- **音訊**：可用的 Windows 預設錄音裝置（例如麥克風或 Webcam 麥克風）。
- **網路**：首次啟動下載模型與執行元件時需要；完成後的辨識與翻譯不使用雲端 API。

> 6 GiB VRAM 已有使用者持續測試運作正常的回報，但仍不代表所有 6 GiB GPU 都保證相容。實際能否順暢使用取決於兩個模型同時載入後的可用顯存；請持續以實機結果為準。

## 🚀 使用方式

**一般使用者（取得已建置的 EXE 後）**

1. 在 Windows 設定好預設麥克風，確認 Windows 已允許桌面應用程式使用麥克風。
2. 啟動程式；首次使用時等待 Qwen3-ASR、Hy-MT2 與本機翻譯執行元件下載、載入。
3. 模型顯示就緒後，按下「開始」；畫面會顯示原文與翻譯。
4. 如需更改語言、短句停頓時間、字幕字體或透明度，開啟設定視窗。

**收聽電腦播放的演講／課程**

現行程式使用**預設錄音裝置**，不是直接擷取系統播放音效的 loopback 功能。最簡單的方式是以 Webcam 或外接麥克風接收喇叭聲音；如果使用虛擬音訊裝置，也需先由 Windows 設成合適的錄音來源。適當調整距離與音量可減少背景雜訊。

## 🛠️ 從 Rust 原始碼建置（開發者）

Rust 專案位於 [`EchiTransRS/`](./EchiTransRS/)，不是儲存庫根目錄。

請先在 Windows 安裝 Rust 工具鏈與所需建置環境，於終端機執行：

```powershell
cd EchiTransRS
cargo test
cargo build --release
```

建置成功後，執行：

```powershell
.\target\release\ramen-listen.exe
```

請注意：**目前沒有提供預先編譯的 EXE**，上述命令也尚未在此版本的 Windows GPU 實機環境完成驗證。使用者端不需另外安裝 Python、Vosk、Ollama 或手動配置翻譯 API。

## 🤖 以 LLM 協助維護

本專案特別採用**讓 LLM 容易理解、定位、替換與維護**的原始碼設計方式，重視清楚的模組責任與資料流，不強求傳統以人類閱讀為優先的排版習慣。

維護規約直接寫在 Rust 原始碼（尤其 `src/main.rs` 檔頭），**不另外建立 `AGENTS.md`**。若使用 AI 修改功能，建議先提供相關模組與需求，並要求維持兩個模型、僅本機翻譯、原文與譯文分離的既有架構。

## 🕰️ 舊版說明

根目錄的 `app.py` 是早期 Python／Vosk／Google 翻譯／Ollama 時期的實作，仍保留作為歷史版本參考。**目前主要開發方向已改為 Rust 版 RamenListen**，舊版所需的 Python 套件與配置不適用於 v0.7。
